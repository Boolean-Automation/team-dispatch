# Learnings

Verified semantic rules for this repo. Each entry captures a constraint that
AI semantic judgment is required to apply — regex/grep can't catch it.

Format per entry:

```
## [LRN-YYYYMMDD-NNN] correction|preference|gotcha

**Logged**: ISO-8601
**Priority**: high|medium|low
**Status**: verified|proposed
**Area**: code|workflow|domain

### Summary
One sentence.

### Details
Paragraph with context.

### Suggested Action
What future agents should do differently.
```
